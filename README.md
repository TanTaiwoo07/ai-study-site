# AI 学习站

个人用的 AI 学习进度盘与概念页。不是教程，是学习产物——学完一个概念才产出一页。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 地图页：六层知识地形、当前阶段待办、检查点倒计时、数学按需清单 |
| `ai-params-guide.html` | 大模型参数：B 值滑杆、MoE 专家池、四类参数、推理旋钮、显存估算、5 题测验 |
| `LEARNING-PLAN.md` | 五阶段学习与建站计划 |

## 本地打开

直接双击 `index.html` 即可。没有后端、没有构建步骤、没有第三方依赖。

## 部署

纯静态站点，可直接挂到 GitHub Pages。启用后：

- 桌面浏览器可"安装"成独立窗口应用（PWA）
- 手机浏览器可"添加到主屏幕"，效果接近原生 App
- Service Worker 会缓存全部页面，断网也能打开

修改内容后，把 `sw.js` 里的 `CACHE_VERSION` 加一，旧缓存会在下次访问时清掉。

## 说明

- 页面内容为教学简化，不构成工程规范。
- 涉及的参数量、显存等数值为量级估算，会随模型迭代过时。
- 显存估算标注为"粗略"，实际占用还受 KV Cache、框架开销、上下文长度影响。
