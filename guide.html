从零开始用它

这篇教程假设你什么都没配过。跟着做，十分钟能读上第一篇论文。

01

它到底是个什么东西

三个独立的部分，共用一套界面：

功能干什么用需要花钱吗
AI 学习站自己写的知识地图和概念页不需要
论文搜索按方向找论文不需要
论文精读让 AI 逐段给你讲需要自己的 API Key
只有「论文精读」要花钱，因为它在调用大模型。一篇论文大约几毛钱到一两块， 取决于你用什么模型。
02

怎么打开（三种任选一种）

方式 A：双击 exe（推荐）

文件在 dist 文件夹里，叫 AI学习站.exe。

双击它，会弹出一个窗口，这就是全部。关掉窗口就是退出。

注意：exe 旁边那个 paper-reader 文件夹不能删， 里面装着你已经解析好的论文。移动 exe 时要连它一起移动。

方式 B：双击 bat 用浏览器打开

文件是 paper-reader\启动阅读器.bat。它会： 起一个本地服务 → 自动打开浏览器。

用完把那个黑色命令行窗口关掉就行。

方式 C：直接看线上的

浏览器打开 tantaiwoo07.github.io/ai-study-site。

优点是不用带文件、手机也能看。缺点是精读功能要联网调 API。

三种方式看到的界面完全一样。exe 和 bat 的好处是不受浏览器跨域限制， 「一键打开论文」才能真正工作。
03

第一次：配一个 API Key

这是唯一需要动手配置的地方。不用怕，就是复制粘贴一串字符。

API Key 是什么

可以理解成一张「充值卡卡号」。AI 服务商用这串字符认人、计费。 你把 Key 填进这个网站，它就直接发给厂商，中间不经过任何服务器。

去哪申请（以 DeepSeek 为例，最便宜）

  1. 打开 platform.deepseek.com 注册账号，用手机号就行。
  2. 左边菜单找「API keys」 点「创建 API key」，起个名字（随便写，比如 my-study）。
  3. 复制那串 sk- 开头的字符 只显示一次，关掉就看不到了，先粘到记事本。
  4. 充值 最少充 10 块就够读很多篇了。不充值调不通。

填进网站

打开精读页面，右上角点「设置」，三个格子这样填：

字段填什么
API 地址https://api.deepseek.com/v1
API Key你刚复制的那串 sk-...
模型名deepseek-chat

填完右上角的状态会从「未配置 API」变成 deepseek-chat，就成功了。

Key 只存在你这台电脑的浏览器里。换电脑要重新填。 如果不想留痕，用完可以在设置里清空。
04

完整走一遍

  1. 打开精读页，点一篇现成的 页面上列着 7 篇已经处理好的论文。第一次点 PIDNet 那一行 ——它最短，45 段，十几分钟能读完。
  2. 看左边目录 按章节分组，标着「必读 / 可略读 / 附录」。不想全读就只点必读的。
  3. 读讲解 每段会给你三段话：这段在做什么、白话解释、它和上下文的关系。
  4. 没看懂就点「没懂，换个说法」 它会换角度重讲，最多换四次。四次还不懂会直接告诉你缺哪个前置知识。
  5. 读完一段，点「检验一下」 它会出一道题，你用大白话回答。然后给你一份诊断：
    · 已掌握什么 · 漏了什么 · 哪里有误解
    答不出来就写「不知道」，这也算有效信息，不会扣分。
  6. 读完整篇，点「下一段」一路走 进度会自动存。下次打开从上次那段接上。
05

想读别的论文怎么办

分两种情况。

情况一：arXiv 上的论文

arXiv 是个论文预印本网站，计算机方向的论文基本都在上面。

  1. 在搜索页找到它的编号 比如 2206.02066。搜索结果里有「复制 ID」按钮。
  2. 打开命令行 按 Win + R，输入 cmd，回车。
  3. 切到工具目录，跑一行命令 
    cd /d "C:\Users\Lenovo\WorkBuddy\AI 深度学习模型\paper-reader"
python m0_fetch_parse.py 2206.02066
    等几秒，它会打印章节结构和质量报告。
  4. 回精读页刷新 新论文会出现在列表里，点开就能读。

情况二：手上只有 PDF 文件

命令换成这个（把路径换成你自己的）：

cd /d "C:\Users\Lenovo\WorkBuddy\AI 深度学习模型\paper-reader"
python parse_local.py "D:\论文\xxx.pdf"
PDF 的效果比 arXiv 差。PDF 里公式是图片，抽出来是碎片； 表格也没有行列结构。能用 arXiv 就用 arXiv。
06

会遇到的问题

点了论文没反应，弹出「自动读取失败」

多半是直接用浏览器双击打开了 reader.html。 浏览器出于安全不允许网页读取同目录的文件。

解决：改用 AI学习站.exe 或 启动阅读器.bat。

提示「调用失败：接口返回 401」

Key 填错了，或者没复制完整。回设置里重新粘贴一次。

也有可能是账户没充值——DeepSeek 需要余额大于 0 才能调用。

提示「接口返回 402 或 余额不足」

账户没钱了。去 platform.deepseek.com 充一点。

提示「接口返回 429」

调得太快被限流了，等十几秒再点。

搜索页搜不出东西

先试试更短的关键词。比如「semantic segmentation」比 「real-time semantic segmentation for autonomous driving」效果好得多。

也可能是网络问题，OpenAlex 在国外，偶尔连不上。

一篇文章要花多少钱

按核心段数算。PIDNet 核心 40 段 ≈ 40 次调用，DeepSeek 大约几毛钱。

SAM 3 那种 20 万字的大论文，全讲要 268 次调用，建议只读核心章节。

「检验一下」每次多两次调用（出题一次、诊断一次）。

我完全不懂 AI，读这些论文有意义吗

先说结论：现在读论文，收益不如先把基础打牢。

这个工具解决的是「读懂一篇具体的论文」，不解决「建立知识体系」。 如果你连反向传播是什么都还不清楚，读 SAM 3 只会得到一堆解释术语的解释。

建议顺序：先用学习站把梯度下降、过拟合、卷积这几块过一遍， 再回来用它读论文。

进度存在哪，会不会丢

存在浏览器本地（localStorage），不上传。

换浏览器、清缓存、换电脑都会丢。重要的话自己记一下读到第几段。

还有问题就问——把报错原文贴出来，比描述「打不开」有用得多。
